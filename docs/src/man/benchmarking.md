# Benchmarking

The package has been benchmarked against thermal-kinematic tools used by the UCLA and Geneva research groups.

Published comparison details are summarized in the README and associated publication references.

A benchmark-oriented script is included in the repository:

```julia
include("examples/Example2D_ZASSy.jl")
```

This scenario is useful for comparing thermal evolution and zircon-age related diagnostics across implementations.
