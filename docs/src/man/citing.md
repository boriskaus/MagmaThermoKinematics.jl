# Citing

If you use MagmaThermoKinematics.jl in published work, cite:

1. The exact software version used to produce the results (for example via the Zenodo archive for releases).
2. Schmitt, A.K., Sliwinski, J., Caricchi, L., Bachmann, O., Riel, N., Kaus, B.J.P., de Leon, A.C., Cornet, J., Friedrichs, B., Lovera, O., Sheldrake, T., Weber, G. (2023). Zircon age spectra to quantify magma evolution. Geosphere 19. https://doi.org/10.1130/GES02563.1

The Schmitt et al. (2023) paper includes benchmarks comparing MagmaThermoKinematics.jl to related software and clarifies solved equations and parameter-sensitivity impacts.

## Responsible Use

Code users are responsible for the results they publish. Numerical-model quality depends on factors such as resolution, timestep convergence, and nonlinear convergence tolerances.
